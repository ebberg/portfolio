# Eric Berg's technical writing portfolio

This portfolio demonstrates my ability to create different documentation types for different audiences, from reference guides for engineers to how-to guides for on-call engineers.

I built this site using modern docs-as-code practices: git for version control, Hugo for static site generation, GitHub Actions for CI/CD, and Vale with the Microsoft Style Guide for quality checks. You can view my portfolio at [ebberg.github.io/portfolio/](https://ebberg.github.io/portfolio/).
